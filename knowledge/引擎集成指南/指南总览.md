# 引擎集成指南

`@emrde/document-engine`（EMR 电子病历文档引擎）的**开发指南**集合，面向在
本仓库之外使用引擎的开发者。

引擎源码已从应用里**物理剥离**到 `packages/emr-document-engine/`，以独立包
`@emrde/document-engine` 分发。它可被 React / Vue / 原生 JS / Electron /
Web Worker / 纯 Node 直接导入：引擎核心零浏览器全局依赖、零框架依赖，平台能力
全部经注入的 `EditorHost` 六元组进入。
